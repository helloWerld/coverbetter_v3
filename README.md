## Cover Better

# Description:

CoverBetter is a powerful AI web application that empowers job applicants to write better cover letters and apply to more jobs by utilizing the professional writing skills of AI models such as ChatGPT, Gemini, and Claude

# Main Features:

- Login via Linkedin, Google, and Facebook
- AI Cover Letter Generator, based on personal resume and a job description
- Customizable settings such as tone, style, writing level, bullet points, etc.
- Cover letter editor to make changes and add personal details
- Importing and saving of resumes for later use
- Exporting of cover letters as PDF or Docx
- AI Job Fit Score: AI enabled job eligibilty grading system, based on resume and job description
- Analytics and tracking
